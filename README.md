### 2. Mzansi Drift (Mobile & Real-Time)

A responsive mobile game built with a single-hold core mechanic and a real-time social layer. It uses **React Native (Expo)** for cross-platform delivery and **Firebase** for instantaneous data synchronization across rankings, friend lists, and a live social feed.

  - **Focus:** Mobile Development, Real-Time Systems, Game Logic (Collision Detection), Firebase Authentication/Storage.

### 3. Kairo AI (Web & AI Integration)

A creative web application that turns visual concepts (user drawings) into downloadable electronic music tracks. This client-server solution utilizes a lightweight **Python Flask microservice** to interface with **Google Cloud Vision AI** for image analysis and **Google Cloud Vertex AI (Lyria)** for audio generation.

  - **Focus:** AI/ML Integration, Client-Server Architecture, Prompt Engineering, React SPA Development.
  - **Technologies:** React, Python Flask, Google Cloud Vision AI, Google Cloud Vertex AI.
